# 首页信息设计

问题：原首页把采购公告压成标题，把状态标签放在主要位置。销售人员看不到采购范围与参与条件，必须逐项进入详情。

## 设计计划

- 对象：矿业设备销售人员，先判断需要什么、能否参与、什么时候截止。
- 色彩：采购蓝 `#193C78`、深墨 `#172D48`、纸白 `#FFFFFF`、浅灰蓝 `#F3F6FA`、截止金 `#F0B840`、辅助灰 `#62748A`。
- 字体：微软雅黑用于需求标题和正文，等线用于辅助信息。需求标题28–34px，正文14–15px，辅助12px。
- 焦点：首屏以一项近期截止采购的实际需求为主视觉。突出采购范围、截止日期和参与条件，不放虚构分数。
- 信息流：默认展示尚可核实的候选与待核实项目，过期公告在全部入口。每项直接显示原文采购范围、交付与资格要求，允许原地展开原文。
- 页面结构：左侧导航收敛为窄工具区；一个采购需求焦点区域，随后是紧凑筛选和完整信息条目。

```text
导航 | 采购机会                  数据更新时间
     | 近期截止采购：实际需求大标题        截止日期
     | 采购范围原文                   参与要求
     | 分类 / 搜索
     | 项目名称 / 采购方 / 时间
     | 采购范围与交付                  资格要求
     | 原地展开原文 / 进入研判
```

## 计划复核

焦点必须是一项真实采购需求，不能把大数字、插画或口号当焦点。正文提取直接来自公告，明确标为原文摘录；缺少信息时提示未识别，不冒充AI结论。AI配置提示降为辅助信息。条目不是重复卡片模板，各区域依据需求、条件、动作组织。

## 代码要求

数据摘录由后端统一提供，不在浏览器逐项请求详情。组件按焦点、筛选、信息条目、原文展开拆分；请求处理集中在hook，避免巨型页面和重复样式。样式统一前缀，保留现有筛选、分页、错误与空状态；原文展开按需加载并处理请求竞态。

## 实际落地与验收

- 真实数据校正后，首屏改为最新采购需求，直接展示采购范围与交付要求；截止日期放在独立琥珀色区域。近期截止保留为独立分类。
- 去掉公告标题的重复后缀，完整标题仍保留在信息流。资格摘录分段，首屏只列主要条款，完整要求可原地展开核对。
- 首页信息直接来自采集正文，不需要配置AI才能阅读。数量、规格、金额不通过文本排版改写。
- 后端原文摘录、设备与采购范围搜索、当前机会筛选均有测试，后端29项通过。
- 类型检查、生产构建通过；1920px、1440px、390px四个页面无横向溢出。
- 浏览器验证通过：入页直接有采购信息；原地展开仅请求当前项目并复用缓存；搜索采购数量、分类和分页正常；人工决定与配置保存原流程通过隔离验收。
- 原建设报告与采集导出文件均未由本次修改写入。

## 反馈修订：目录式浏览（2026-10-09）

用户反馈首页更像逐条阅读原文，卡片过大，无法快速浏览多个采购项目。本轮把首页任务重新收敛为“先扫选，再进入详情”：

- 信息层级：页面顶部保留标题、同步状态、错误提醒和筛选；采购项目使用紧凑目录卡。卡片只显示清理后的两行标题、单行采购方、一个来自公告的具体采购线索、最多两个事实芯片和显眼的截止日期。
- 摘录原则：线索优先取公告中的数量、规格、交期、工期等完整短句；没有可靠短句时明确提示进入详情核对。不在首页截断资格要求、联系方式、状态堆叠或 AI 摘要，也不把表格残片加工成推断。
- 标题原则：长来源标题只在卡面保留可辨识的设备或工程主题，项目原题仍通过详情和卡面悬停标题保留；来源代码不占据两行标题的主要空间。
- 浏览密度：桌面默认三列，宽屏四列，中等宽度两列，移动端一列；卡片保持约 230–250px 的紧凑高度并填充可用列宽，让首屏同时看到多项采购。每张卡为完整链接，支持键盘聚焦、悬停、普通点击和 Ctrl/⌘ 点击。
- 特别提醒：仅在当前候选中确有未来七天内截止项目时，以一条窄的“临近截止”提示突出最早截止项目；不使用“推荐”等没有 AI 依据的措辞。其余项目保持同一目录层级。
- 连续浏览：从卡片进入项目详情前，将本标签页内的已知筛选、搜索草稿、高级筛选开关和滚动位置写入受保护的 sessionStorage；返回首页时恢复，过期或格式不明的数据会被忽略，不保存凭据或原文。

```text
机会池 / 同步状态
数据提醒（仅异常时）
分类 / 搜索 / 高级筛选
临近截止（仅有客观七天内截止项目时）
采购信息
┌────────────┐ ┌────────────┐ ┌────────────┐
│ 标题两行    │ │ 标题两行    │ │ 标题两行    │
│ 采购方一行  │ │ 采购方一行  │ │ 采购方一行  │
│ 数量/规格线索│ │ 交期/规格线索│ │ 数量/交期线索│
│ 事实芯片    │ │ 事实芯片    │ │ 事实芯片    │
│ 截止   查看详情│ │ 截止   查看详情│ │ 截止   查看详情│
└────────────┘ └────────────┘ └────────────┘
```

## 卡片版最终验收（2026-10-09）

- 1440×1000 首屏完整显示6张卡片；每张约236px高。1920px采用4列，手机单列，分类横向滑动。
- 数量和交付只取明确原文；已排除“2.1项目概况”被误读为“2.1项”，以及表头被当作规格的情况。
- 点击卡片进入详情，立即可见采购范围和交付要求；资格完整摘录按需展开，联系人保留在详情。
- 搜索、翻页、键盘聚焦、整卡点击、返回原筛选及分页均通过浏览器验证。截图检查电脑和手机；四个页面无横向溢出或运行错误。
- 生产构建和文本保真检查通过；保留此前设计记录作为修改历史。
