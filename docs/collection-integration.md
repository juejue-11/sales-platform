# 一个平台中的采集与筛选

信息采集和采购工作台共用网页入口，代码与数据职责保持独立。现有两个目录不搬迁，不合并数据库，也不复制历史证据。用户打开原来的 `启动平台.cmd`，在“信息采集”管理来源、执行采集和查看结果，在“采购需求”阅读资料、研判和跟进。

## 执行与反馈

平台后端通过固定参数的 Python 子进程调用采集模块。控制入口是 `python -m collector.control --config CONFIG --data DATA`，读取标准输入的 JSON 请求；实际采集仍使用 `python -m collector ... run`。筛选端不直接修改来源配置或采集数据库。

“立即采集”立即返回任务，网页轮询状态，不占住普通浏览请求。采集模块在开始时发布已提交资料，每完成一条公告就原子更新交接文件；平台在进程仍运行时持续读取新快照并导入，采购列表与首页自动刷新。手动采集的增量导入沿用用户主动操作语义，不依赖独立的自动检查开关，也不等待 AI 阅读或研判完成。

导入串行执行，快速连续发布可合并为最新完整快照；期间发生的后续更新会继续接收。任务结果累计新增/更新次数，总量与未变数使用最近快照，不把重复全量快照累计成新增项目。瞬时导入失败保留已有结果并继续重试；超时或后续来源失败也不会撤销已导入数据。

平台整批采集默认上限为 2 小时，与原 Windows 每日任务一致；可通过 `SCREENING_COLLECTOR_TIMEOUT`（秒）覆盖。达到上限会终止平台发起的采集，已经发布、导入的记录继续可见。附件较多的来源可能超过 30 分钟，不能据此判为卡死。单条公告仍在正文和附件处理提交后发布，尚未获得或未完成处理的资料不会冒充已完成。

采集和配置修改共享数据目录下的操作系统文件锁。平台重复点击、独立命令和 Windows 定时任务发生冲突时返回繁忙，不同时写库；进程退出后锁自动释放。状态读取不创建采集数据库。历史来源执行中断不能显示为成功。

## 自动运行

每日自动采集继续使用 Windows 的“销售平台信息采集”任务。平台可以读取、启用、停用和调整时间；仅保存设置时修改任务。未注册时首次启用会注册当前采集目录的运行脚本。保留关机后恢复执行机制，电脑关闭期间不能采集。

网页后端不新增第二套调度器。Windows 定时采集可在网页服务停止时独立执行；网页恢复后按已有自动导入设置接收最新导出。停止网页平台会停止它自己发起的采集子进程，不停止独立的 Windows 定时采集。

系统任务权限不足、非 Windows 环境或设置 `COLLECTOR_SCHEDULER_DISABLED=1` 时，页面明确显示自动采集管理不可用，其他功能仍可使用。隔离测试必须禁用任务计划。

## 路径与解释器

默认采集目录为平台旁边的 `销售平台信息采集系统`。可通过下列环境变量覆盖：

| 配置 | 用途 |
| --- | --- |
| `SCREENING_COLLECTOR_ROOT` | 独立采集模块根目录 |
| `SCREENING_COLLECTOR_PYTHON` | 指定采集模块 Python；否则读取采集目录的 `data/python_path.txt`，最后使用当前 Python |
| `SCREENING_COLLECTOR_CONFIG` | 来源配置文件，默认采集根目录的 `sources.json` |
| `SCREENING_COLLECTOR_DATA` | 采集数据根目录，默认采集根目录的 `data` |
| `SCREENING_IMPORT_PATH` | 既有筛选导入路径；执行采集时须与该采集数据目录的 `export/records.jsonl` 一致 |
| `SCREENING_ARCHIVE_ROOT` | 既有归档读取根目录，通常为采集数据根目录 |

更改平台导入路径不会把另一个采集目录的文件悄悄导入。路径不匹配时先修正配置；保留状态查看入口。

Windows 每日任务使用采集模块根目录中的默认 `sources.json` 和 `data`。如果显式使用其他配置或数据路径，平台会拒绝调整该每日任务，避免计划执行与手动采集指向不同资料；自定义路径需独立安排调度。

`安装依赖.ps1` 同时准备采集依赖，优先保留采集模块已有解释器；没有运行环境时创建采集模块自己的虚拟环境。筛选平台保存的模型密钥不会传给采集子进程；采购阅读与研判仍按平台原有模型配置执行。

## 验证

后端新增集成测试使用临时数据库和替代采集进程。采集控制测试覆盖原子配置写入、互斥和任务计划的替代响应。真实 CLI 到网页的隔离验收使用 `tools/qa/serve_collection_fixture.py` 与 `tools/qa/collection_api.cjs`，只访问本机模拟公告，不调用模型、不修改真实来源或 Windows 任务。
