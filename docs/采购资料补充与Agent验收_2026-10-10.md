# 采购资料补充与 Agent 验收

## 原因

问题确实在三个环节：采集器只保存公告网页，没有抓取正文外的附件；采购摘要只读公告正文；原 Agent 只有查询已有资料的工具，不能主动读取附件。

## 已完成

- **采集**：发现公开附件，下载原件、提取 PDF 文字，独立保存文件哈希、解析状态和历史版本。附件变化也会产生新版本，公告正文保持原样。
- **展示**：采购信息优先展示范围、交付要求和完整物料行；可搜索、分页，并按文件和页码回到来源核对。标题中的设备词不再作为已解析采购的设备兜底。
- **Agent**：新增按可信记录编号读取公开附件的工具。范围、规格或交付资料不足时，要求先尝试补充，再生成判断；附件理由必须通过真实文档引用校验。
- **已有项目**：可以单独补充采购资料，无需调用模型。旧分析和决定历史保留；新增实质资料后，旧分析标为待复核。

清单为 **36 页、143 项物料**，包含普碳中板、花纹板、镀锌方管等 21 种物料名称。第一行为普碳中板、4mm、Q235B、5.0t。

交货地：**本溪市**。交货期：**合同签订后，供货商按通知供货量三日内供完**。没有把投标截止日当成交付期限。

- 本地模拟模型与真实 Pi SDK 完成 SSE → 主动读取 PDF → 143 项采购事实 → 附件引用校验的完整流程，没有调用生产模型。
