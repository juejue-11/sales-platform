# 商机判断工作台

根据《销售平台：筛选与 AI 方案平台建设报告》搭建的本地网页平台。

流程：采集数据自动接入 → 明确条件初筛 → AI 判断与可选方案 → 人记录选择及下一步。

## 打开平台

双击本目录的 `启动平台.cmd` 即可启动并打开网页。也可以运行：

```powershell
powershell -ExecutionPolicy Bypass -File .\启动平台.ps1 -OpenBrowser
```

地址：<http://127.0.0.1:8766>。再次运行启动脚本会复用已启动的平台。

双击 `停止平台.cmd` 或运行以下命令停止服务：

```powershell
powershell -ExecutionPolicy Bypass -File .\停止平台.ps1
```

初次安装或代码更新后，可运行 `安装依赖.ps1`。本机已提供独立Python环境；安装脚本支持Codex自带运行时，其他机器需Python、Node.js 22.19或更新版本与pnpm。安装脚本同时构建Pi SDK分析组件与前端。

## 首次使用

1. 在“机会池”查看真实项目，使用类别、规则状态和关键词筛选，打开详情看需求与原文。
2. 在“业务配置”填写公司范围、可提供产品、能力说明和方案例子。明确排除项用于规则初筛；未知能力保留为待核实。
3. 填写兼容OpenAI的接口地址（例如服务商提供的 `/v1` 地址）、模型和API密钥，开启AI。模型及接口需支持流式Chat Completions和工具调用。Pi SDK按需读取项目原文、关联资料与公司能力，并生成JSON判断和方案；密钥仅在后端保存，页面不会读回密钥。首次启用后，符合条件的项目自动排队分析。
4. 在“处理状态”确认导入成功、来源覆盖和AI任务进展，可重试失败任务。
5. AI结果完成后，对比方案，记录负责人、下一步及选择理由。也可直接人工标为跟进、待核实或关闭。

缺少模型时平台显示“模型未配置”，保留初筛与人工处理；不会用样例方案冒充AI结果。缺少公司资料时，模型应说明待确认项。

## Pi SDK分析

`agent-runtime/`将Pi SDK嵌入专用的TypeScript分析组件。Python任务队列通过子进程管道传入配置和资料，每次分析独立创建内存会话；无需另开Agent服务。密钥不放进命令行参数。

Agent可以查询项目原文、公司能力、关联公告，并按需读取当前公告的公开采购附件。详情页显示实际查询活动，规则初筛、引用校验、人工选择和历史记录由平台管理。附件工具按可信记录编号调用，由后端下载并解析同来源的公开文件，保留文件哈希和引用依据。

采购信息区直接展示物料名称、规格、材质、数量和交付要求，支持检索明细、按页查看来源。已有项目可点击“补充采购资料”单独读取附件，无需调用模型；新增资料会保留原分析，内容变化时标记待复核。无法下载、旧版 Word 或扫描 PDF 等缺口会明确显示，不会标成完整资料。

默认每次SDK执行最多6轮模型调用、12次工具调用、180秒，向模型请求的单次输出限制为4096 tokens，并在本地限制整次执行的文本输出不超过256 KiB；无效结果最多再生成一次。异常会显示为失败任务，可以修复后重试。设置`SCREENING_AI_ENGINE=single_call`可显式使用原来的单次调用路径，平台不会在SDK失败时自动切换。

## 数据与更新

- 默认读取旁边采集系统的 `data/export/records.jsonl`，在配置页可更改路径和检查频率。
- 运行期间自动检查文件更新；全量重复导入不重复创建项目。
- 首页显示采集文件更新时间、来源覆盖与试运行缺口；文件超过48小时未更新会提示。最近导入时间另在“处理状态”展示。
- 正文、重要公告字段或业务配置变化后，旧判断标记待复核；人工决定和历史判断保留。
- 确认重复与同项目公告可关联；疑似重复提示需要人确认。
- 页面提供原文链接与归档下载；采集系统数据保持只读。
- 本平台数据、设置、密钥及日志在 `data/`，该目录不进入Git。
- 电脑关机后服务停止；重新运行启动脚本恢复，后台任务在服务运行时执行。

## 开发

```powershell
.\.venv\Scripts\python.exe -m uvicorn backend.main:app --host 127.0.0.1 --port 8766
```

前端在 `frontend/`，执行 `pnpm dev`。开发代理接口到8766；生产执行 `pnpm build` 后由FastAPI同源提供页面。

后端验证：

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements-dev.txt
.\.venv\Scripts\python.exe -m pytest backend/tests -q
```

接口约定见 `API_CONTRACT.md`。平台默认用于本机内部决策；面向采购客户的发布页面按后续业务范围增加。
